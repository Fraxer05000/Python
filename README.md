# Celdas de combustible microbianas | UNEMI

Sitio educativo completo con cuatro páginas, fotografía del autor Ing. Samuel Emilio Valle Asan y tres presentaciones de 26 diapositivas (78 en total).

## Estructura
- `index.html`: Inicio, fotografía y ruta de aprendizaje.
- `estructura.html`: estructura, fundamentos y funcionamiento.
- `transferencia.html`: microorganismos electroactivos, EET y biopelículas.
- `aplicaciones.html`: aplicaciones y evaluación bioelectroquímica.
- `styles.css` y `site.js`: estilos adaptables a móviles y navegación.
- `assets/samuel-valle.jpg`: fotografía aportada por el autor.
- `assets/{estructura,transferencia,aplicaciones}.pdf`: presentaciones institucionales completas, 26 páginas cada una.

## Publicación
1. Abrir **https://github.com/Fraxer05000/Python/settings/pages**.
2. En *Build and deployment*, escoger *Deploy from a branch*.
3. Seleccionar rama **mfc-unemi-site** y directorio **/(root)**.
4. Guardar y consultar el enlace **Visit site** cuando GitHub complete el despliegue.

No se ha activado GitHub Pages mediante el conector, por lo que la URL publicada debe verificarse después.

## Google Sites
GitHub no edita automáticamente Google Sites. Para cumplir una tarea que requiera URL de Google Sites, crear un sitio en https://sites.google.com/new con **Inicio**, **Estructura y funcionamiento**, **Transferencia de electrones** y **Aplicaciones y desempeño**. Insertar las páginas de GitHub publicadas usando *Incorporar* o enlazarlas desde la navegación. Validar que se muestran y publicar Google Sites. Entregar la URL `sites.google.com`.

## Notas
Los diagramas del sitio son conceptuales, no datos experimentales. Los archivos de Google Slides enlazados pueden requerir autorización institucional, mientras que los PDF publicados en GitHub Pages se encuentran disponibles como recursos estáticos.
